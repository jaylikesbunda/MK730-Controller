Notes
Effects run on firmware (mode 41 01). Manual paint uses 41 02 + c0. Switching is automatic. Save to P1–P5 from Profiles tab (50 55).
Wave directions: 00 L→R, 04 R→L, 02 B→F, 06 F→B. Ripple 0x80 = random color per press.

RE & setup
Linux:
  lsusb -v -d 2512:
  sudo cp udev/99-mk730.rules /etc/udev/rules.d/ && sudo udevadm control --reload
  Wireshark + usbmon, filter usb.idVendor==0x2512

Windows:
  Wireshark + USBPcap, Portal in VM or host
  Bind Interface 1 to WinUSB only if needed (Zadig), keep IF0 HID.

Calibrate keymap: see docs/RE_MACROS.md (record tool pattern).
Macros: capture macro create/assign/delete in Portal, attach pcapng.
